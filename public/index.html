Cara pakai di website

Tidak perlu install database atau menjalankan backend sendiri. Cukup muat client dan panggil satu fungsi.

Tambahkan script annotator

<script src="https://api.cidict.org/static/cidict-annotator.min.js" charset="UTF-8"></script>

Anotasi elemen yang diinginkan

<script>
  cidict.annotate('.chinese-text', { theme: 'light' });
</script>
Preferensi seperti tema dan mode tampilan tersimpan otomatis di browser pengunjung (localStorage).

Kustomisasi

Sesuaikan tampilan dan perilaku — mulai dari pengaturan sederhana hingga kontrol untuk situs dengan konten panjang.

OpsiNilaiKeterangan
themelight (default) | darkWarna tema UI popup & dock
showInlinetrue (default) | falseTampilkan atau sembunyikan pinyin inline
showPopupstrue (default) | falseAktifkan atau nonaktifkan UI definisi
displayModepopup (default) | docked | bothTampilan UI definisi
dockAlignleft | right (default)Posisi panel dock pada desktop
loadingselector | { target, show }(Opsional) Elemen indikator loading
chunkSize200–10000 (default 2000)Ukuran potongan teks untuk konten panjang; isi 0 untuk menonaktifkan
maxConcurrency1–6 (default 3)Maksimum request anotasi paralel

Contoh penggunaan lengkap

cidict.annotate('.artikel', {
  theme: 'light',
  showInline: true,
  showPopups: true,
  displayMode: 'both',
  dockAlign: 'right',
  chunkSize: 2000,
  maxConcurrency: 3,
  loading: {
    target: '.loading-indicator',
    show: 'flex'
  }
});

Referensi endpoint

Base URL: https://api.cidict.org. Semua response berformat JSON.

GET/api/health
Status server: versi backend, versi data kamus, jumlah entri aktif, dan mode segmentasi. Cocok untuk monitoring & smoke test.
POST/api/annotate
Body JSON: { "text": "…" } → balasan { tokens, defs, v } berisi hasil segmentasi kata, pinyin, dan definisi.
Rate limit: 120 request/menit per IP (HTTP 429 + header Retry-After bila terlampaui). Untuk teks panjang, pecah menjadi beberapa request (client bawaan melakukannya otomatis via chunkSize).
GET/api/lookup?text=…
Definisi ringkas untuk satu kata/frasa. Contoh: /api/lookup?text=%E5%AD%A6%E4%B9%A0
POST/api/seg-reloadadmin
Muat ulang konfigurasi & bangun ulang leksikon tanpa restart server. Dari localhost bebas token; dari luar wajib token (Authorization: Bearer atau ?token=).

Ingin menjalankan backend sendiri?

Backend tersedia sebagai project Node.js — cukup npm start di VPS atau server apa pun yang mendukung Node.js 22.5+. Kamu pegang penuh data, rate limit, dan konfigurasi.
